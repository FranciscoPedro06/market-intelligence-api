# market-intelligence-api

Parte do **Market Intelligence Ecosystem** · Produto de dados: *Flight Intelligence Platform*.

## Papel neste ecossistema
Camada de **exposição**: servir os indicadores de confiabilidade para responder à pergunta-âncora *"nesta rota, qual companhia é mais confiável?"*. Não contém regra de cálculo.

## Contratos
- **Entrada:** indicadores de confiabilidade — contrato **C2**.
- **Saída:** consulta por rota ao consumidor — contrato **C3**.

Contratos, princípios e governança vivem no repositório de governança:
https://github.com/FranciscoPedro06/Market-Intelligence-Ecosystem

## Estado
Repositório **inicializado** (estrutura mínima). Sem implementação e sem tecnologia definida. Aguardando a **Sprint 1 — Walking Skeleton**.
